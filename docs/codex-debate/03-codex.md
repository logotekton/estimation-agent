**판정**

X-1 LibreDWG: **승복.**  
제안한 스파이크 기준은 내 지적의 핵심을 제대로 닫습니다. 특히 silent-drop 0건, 한글/SHX/인코딩 별도 축, PROXY_ENTITY·ACAD_TABLE 출현율 측정은 필수입니다.  
C-1도 **승복**합니다. “벡터 PDF = 텍스트 파싱 가능”은 위험한 가정입니다. AutoCAD/대체 CAD의 SHX 플롯, outline화, subset font, glyph path 변환 때문에 PDF 텍스트 추출율을 DWG 스파이크와 같은 급으로 검증해야 합니다. DXF와 벡터 PDF를 같은 1급 입력으로 묶으면 안 되고, PDF는 “텍스트 추출 가능 벡터 PDF”와 “기하화된 벡터 PDF”로 등급을 나눠야 합니다.

X-2 GPL: **조건부 승복.**  
“전파 차단 불가”라고 단정하면 과장이라는 반박은 맞습니다. exec/fork + 파일 기반 데이터 교환 + LibreDWG 원본/수정 소스 제공 + 명확한 라이선스 고지라면 방어 논리는 있습니다.  
다만 “mere aggregation으로 방어 가능”도 아직 단정하면 안 됩니다. 설치 패키지, 프로세스 생명주기, 내부 API 의존성, 제품 문구, 온프레미스 고객에게 제공되는 바이너리 구성에 따라 결론이 달라집니다. 제안한 법무 게이트 + ODA 원가 반영 + SaaS LibreDWG 유지 조합이면 **계획 단계 리스크는 닫힌 것**으로 보겠습니다. 단, 온프렘 GA 전이 아니라 **온프렘 유료 파일럿 계약 전** 법무 검토가 맞습니다.

X-3 평가 통계: **조건부.**  
FDA급 설계를 파일럿에 요구한 건 아니라는 반박은 맞습니다. 하지만 “내부 게이트”라도 숫자가 의사결정을 좌우한다면 통계 설계는 필요합니다.  
제안한 cluster-robust CI, NI margin 사전 지정, McNemar/GEE, 검정력 통과 전 NI 선언 금지는 충분히 좋은 수정입니다. 다만 파일럿 설계도 바꿔야 합니다. 최소한 같은 도면에 대해 수작업/시스템 보조 결과를 paired로 만들고, 독립 adjudicator가 blind 또는 최소 masked로 escaped defect를 판정해야 합니다. “검토 완료 BOQ를 사후 GT로 축적”하면 시스템 산출물이 GT에 오염될 수 있습니다.

X-4 철근/룰팩: **조건부 승복.**  
철근을 2a 허용오차 대상에서 제외하는 수정은 맞습니다. 프로젝트 특기시방·유의서 레이어 추가도 필요충분에 가깝습니다.  
내 원 지적은 “오버라이드 레이어가 없다”가 아니라 “우선순위·충돌해결·검증체계가 없다”였습니다. 정본 → 발주처 → 프로젝트 특기시방/유의서 → 사무소 관행의 precedence, 룰 테스트, 변경 이력, 승인권자를 명시하면 이견 없습니다.

X-5 벽식 지표: **승복.**  
추가 3지표가 정확합니다. 특히 carry-forward 오류율은 벽식 2b의 성패를 가르는 지표입니다.

X-6 용도 c: **승복.**  
C-4는 중요한 누락입니다. 발주 내역 검증 상품이라면 발주 내역서 파싱과 BOQ 라인 매칭이 본체입니다. 파일럿에서 수동 대조로 시작하는 것은 현실적이지만, 용도 c를 단독 상품으로 팔기 전에는 이 모듈이 “지금 안 만드는 것”에서 빠져나와야 합니다. 구매 경제 인터뷰 병렬 추가도 동의합니다.

**자체 발굴 논점**

C-2 N=50 도면 소싱: **승복.**  
구조적 모순입니다. N=50을 낮추기보다 게이트를 2단으로 나누는 게 맞습니다. 1차 smoke는 NDA 샘플·협력사·기존 공개 PDF의 원본 요청 등으로 N=10~20, 2a 착수 전 full gate는 N=50. ZWCAD/CADian 샘플은 의도적으로 포함해야 합니다.

C-5 리비전 좌표계: **승복.**  
스키마 v0에 기하 앵커링 전략이 들어가야 합니다. 절대좌표 기반 carry-forward는 깨집니다. 그리드 교차점, 주요 축선, 블록/태그, affine transform, feature matching 기반 상대 좌표를 써야 합니다.

C-6 뷰어 후보 3 순환 의존: **승복.**  
반드시 결합 매트릭스에 명시해야 합니다. “원본 래스터 배경”은 누가 신뢰성 있게 렌더링하느냐가 핵심입니다. LibreDWG 렌더가 불충분하면 ODA, headless CAD, 고객 제공 PDF, 사전 플롯 워크플로우 중 하나가 필요합니다.

C-7 CAD 파싱 엔지니어 리드타임: **승복.**  
5~6개월 추정은 CAD 파싱 엔지니어가 이미 있거나 즉시 투입된다는 전제입니다. 적산 전문가와 같은 수준으로 즉시 착수 트리거를 넣어야 합니다.

C-8 GT 2건 2인 산출: **승복.**  
n=2로 inter-annotator 편차를 추정하고 δ 근거로 삼는 건 약합니다. 1차 웨이브 3~5건이면 최소 3건, 가능하면 전건을 2인 산출해야 합니다. 비용이 부담이면 프로젝트 전체가 아니라 공종/부재 풀을 층화 샘플링해 2인 adjudication 범위를 넓히는 방식이 낫습니다.

**남은 이견**

1. X-2: “mere aggregation으로 방어 가능”은 법무 검토 전까지 단정 금지. 계획 리스크는 닫혔지만 법적 결론은 아님.  
2. X-3: 수정안은 충분하지만, paired protocol과 독립 adjudication을 파일럿 설계에 넣어야 함.  
3. X-4: 오버라이드 레이어만으로는 부족하고 precedence/충돌해결/룰 검증 체계까지 명시해야 함.

그 외 항목은 이견 없습니다.
