# Codex 라운드 4 — 절충 수용 및 룰·검증·책임 반론

## 잔존 이견 판정

1. **C-6 Fable 절충 수용.** frozen holdout 최소 1건은 초기 임시선으로 두고, 신규 프로젝트 첫 패스 지표를 튜닝 전 고정한다. 평가 manifest는 기존 룰 변경 이력에 실행 스탬프를 더하는 수준으로 제한한다. holdout 1건으로 일반화 주장은 하지 않는다.
2. **C-7 Fable 절충 수용.** 위험 지배 hard quota와 관측 공변량을 분리한다. quota 미달·실패 stratum은 지원/판매 claim matrix에서 제외한다. aggregate가 stratum 실패를 덮지 못한다.
3. **C-8 Fable 절충 수용.** 수치 confidence를 만들지 않고 이산 플래그를 쓴다. §0의 영향액 상위 검토는 단가가 없으면 위험 tier 상위+수량 이상치로 대체한다.
4. **신규 장치 반입 규칙 수용.** 각 장치는 차단하는 잘못된 행동, 비용 상한, 오너를 한 줄로 기록한다. 별도 거버넌스 시스템이 아니라 계획서 작성 규칙으로만 둔다.

## 신규 이견

### C-9 (P0) 룰 precedence가 사무소 관행에 과도한 권한을 부여

§4는 `정본 → 프로젝트(특기시방·유의서) → 사무소 관행` 순서에서 하위가 상위를 override한다고 한다. 이 문면이면 사무소 관행이 명시적 발주처/프로젝트 요구를 덮는다. 고객 오버라이드 표시만으로는 계약 위반을 막지 못한다. 사무소 관행은 상위 규정이 침묵할 때만 default를 채우고, 명시적 프로젝트 요구를 바꾸려면 권한자 승인과 사유가 있는 예외 레코드가 필요하다. 적용 우선순위는 구체성뿐 아니라 법적/계약적 권위를 보존해야 한다.

### C-10 (P1) 이중 모델 교차검증의 독립성 착시

§4의 `이중 모델 교차로 불일치 플래그`는 같은 공급자/유사 학습 데이터 모델의 상관 오류를 잡지 못하며, 합치가 정확성 증거처럼 오해될 수 있다. 표 구조화 품질은 두 모델 투표보다 스키마 제약, 셀 합계·행열 일관성, 원문 좌표 링크, 결정론 OCR/text extraction 대조, 불일치 시 인간 확인으로 검증해야 한다. 두 모델은 탐색적 보조일 뿐 gate나 confidence 근거가 되어선 안 된다.

### C-11 (P1) 확인 클릭 로그의 면책 과신과 checkbox fatigue

§0·§9는 항목별 확인 타임스탬프를 면책의 사실적 근거로 결합한다. 클릭은 실질 검토를 입증하지 못하고, 전건 확인 강제는 마감 압박에서 형식적 일괄 승인과 alert fatigue를 유발한다. 로그는 제품 안전·감사 증적이지 면책 보증이 아니다. 영향액/위험 tier 기반 검토 정책, 일괄 승인 제한, override 사유, 비정상적으로 빠른 확인 탐지 등 검토 품질 통제가 필요하며 법적 효력은 관할 법무 검토 대상으로 낮춰야 한다.

## Fable 판정 요청

C-9~C-11에 승복/반박/절충하고, 이전 네 절충안의 수용으로 이견이 닫혔는지 확인하라. 특히 신규 장치가 과잉 프로세스로 변하지 않는 최소 수정안을 제시하라. 마지막에 현재 이견 목록을 작성하라. 파일은 수정하지 마라.
