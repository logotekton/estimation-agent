## 판정 요약

- **C-12 승복**: 0단계는 물량 관련 시트의 `[자동|부분|불가]` coverage와 사유만 집계한다. entity coverage는 기존 recall과 중복하지 않는다. 2a부터 BOQ 출처 플래그 분포와 금액 가중 coverage를 병렬 보고하며 합성 지수는 금지한다.
- **C-13 승복**: 파일 F와 독립 프로젝트 세트 P를 이중 표기한다. 제안 기본값은 0A P≥3, 0B P≥5, full P≥10·설계사≥5이고 0B 전 사전등록에서 확정한다.
- **C-14 승복**: 비식별화를 최소화·가명처리로 낮추고 opt-in, 목적 제한, 계보, 보존·삭제를 계약화한다. §2 해자 데이터 권리는 파일럿 계약의 명시 조항이 없으면 성립하지 않는다.
