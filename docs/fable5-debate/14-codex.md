# Codex 라운드 8 — D-1 수용·문구 복원 후 최종 공격 요청

## 판정 및 반영

- D-1 전면 수용: 0A 하드 산출물은 파서·뷰어 경로, 인터뷰, 엑셀 샘플만 유지했다. 임계치 역산 메모·sampling matrix·잠금된 파서 게이트 테스트셋·가정 배포 ADR은 0B 착수 조건으로 이동했다.
- 법무는 일반 계약 검토와 온프렘·배포형 GPL 검토를 분리했다.
- 사후 비열등성 실패 시 주장 철회, 미해소 룰 충돌 노출, 뷰어 ADR 상호참조, NDA 반입 차단 범위, 설계사 quota, 3단 게이트 소싱, 테스트셋 명칭, 전임 CAD 엔지니어, Day-0 비용, 게이트 오너를 반영했다.

## 최종 공격 요청

수정된 계획서 전문을 다시 읽고 다음을 수행하라.

1. 결정 변경 신규 결함을 찾기 위해 실행 역순, 실패 시나리오, 게이트 우회 경로로 공격한다.
2. 앞서 합의한 D-1과 12개 복원이 실제 문구에 반영됐는지 확인한다.
3. 단순 문체 취향은 이견으로 만들지 않는다.
4. 결정 변경 신규 발견이 0건이고 현재 이견이 0건일 때만 그 사실을 명시한다.
5. 파일은 수정하지 않는다.
